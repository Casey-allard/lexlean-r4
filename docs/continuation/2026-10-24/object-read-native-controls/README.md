# Read33 native development source

See [RESULTS.md](RESULTS.md) and [results.json](results.json) for current reviewed-source status: all official Read33 native phases remain **NOT_RUN**.

`candidate/` preserves exact frozen sources, metadata, semantic preimage and correspondence evidence. `design/` contains the explicit representation design and SPEC. `reviews/` contains completed source and invocation reviews. `invocation/` contains the exact one-phase adapter and static comparison. `portable-bindings.json` resolves original source paths through committed files or byte-pinned archive members. This is a development checkpoint, not proof or product acceptance. Do not execute historical scripts directly on a new host; preserve their bytes and review a concrete environment binding.
