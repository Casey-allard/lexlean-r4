This archive preserves the 324 unique text contents identified in the bounded
Object257/product-resumption inventory, including 351 original and alias paths.
`inventory.json` maps original paths to byte-identical files under `files/`.
The original inventory is a dated observation before archival, so its
“unmatched” status describes the pre-archive Git tree.

All files are inert historical provenance. The `.source.txt` copies include
authoring/audit scripts with historical absolute paths and exclusive writes;
do not execute them as current portable tools. Failures, superseded proposals
and partial observations remain failures, superseded and partial. Archival
does not promote any proof or component into acceptance. Current instructions
are in ../../CONTINUATION.md, and native-tested LexLean sources are in the
finite fixture and draft continuation packet.

Five raw compiler artifact trees, compiler binaries and caches are excluded.
This does not assert every historical artifact is present on GitHub. New
acceptance requires actual artifacts or a fresh official compiler run.

Coverage outside the enumerated scope is separately recorded; no other labs
or unrelated data were changed.
